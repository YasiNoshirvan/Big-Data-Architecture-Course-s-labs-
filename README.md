# Big Data Architecture Labs

This repository contains a collection of typed lab notes and exercise solutions completed for the **Big Data Architecture** course.

The labs mainly focus on two big data processing paradigms:

- **Hadoop / MapReduce**
- **Apache Spark / PySpark**

Each original lab note contained two sections: one for Hadoop MapReduce and one for PySpark.  
For better organization, the solutions have been separated into two main folders.

## 🐘 Hadoop / MapReduce

The `Hadoop/` folder contains MapReduce-style solutions, generally structured around:

- Mapper logic
- Reducer logic
- Key-value pair design
- Filtering records
- Aggregation
- Counting and ranking
- Handling time-based conditions
- Selecting records based on business rules

These files are written as typed pseudo-code / Java-style MapReduce notes.

---

## ⚡ PySpark

The `PySpark/` folder contains Spark RDD-based solutions, including operations such as:

- `map`
- `filter`
- `join`
- `leftOuterJoin` / `rightOuterJoin`
- `fullOuterJoin`
- `reduceByKey`
- `groupByKey`
- `distinct`
- `flatMap`
- `saveAsTextFile`

The exercises cover practical big data processing scenarios such as sales analysis, user activity, purchases, server patches, robots, data centers, meetings, online courses, cars, and water consumption.
