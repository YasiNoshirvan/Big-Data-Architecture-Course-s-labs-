# Big Data Architecture Labs — Code Format

This repository contains Big Data Architecture lab solutions organized in code-file format.

The labs are divided into two main folders:

- `Hadoop_Java/` — Java-style Hadoop / MapReduce solution notes
- `PySpark/` — PySpark solution notes

> Note: The original material was typed as study notes / pseudo-code.  
> The files are organized with `.java` and `.py` extensions for better GitHub readability and syntax highlighting, but some files may require syntax cleanup before execution.

## Important Note

These files are intended mainly for documentation, revision, and portfolio presentation.  
They show the logic and structure of the lab solutions, but they are not guaranteed to run without modification.

To make them fully executable, the following may be needed:

- Correct Java / Python syntax
- Dataset schemas and real input paths
- Hadoop job configuration
- SparkSession / SparkContext setup
- Type conversions
- Output path cleanup before running
